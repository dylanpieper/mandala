<h1 align="center">Mandala</h1>

<p align="center"><em>Notes dissolve into sand<br>Unless you set them in stone</em></p>

Mandala is a minimalist markdown notes app built around impermanence. It is Obsidian's file model with one change: every note begins as sand and will dissolve, unless you keep it.

A note lasts a breath, a sun, or a quarter, half or full moon. To keep it, hold **Set in stone** and give a reason. Your notes stay plain files. Edit them anywhere, such as Obsidian on your phone.

No accounts, no subscriptions, no network, no AI.

## Download

Get the latest version for macOS or Windows from [Releases](https://github.com/dylanpieper/mandala/releases). Neither is signed yet:

- **macOS**: at first open, go to System Settings, then Privacy & Security, and choose Open Anyway.
- **Windows**: if Windows warns you, choose More info, then Run anyway.

At first open, choose your vault and which folders become stone. Mandala takes a snapshot of the vault first.

## Build from source

You need Rust 1.99 or later and Node 20 or later. On macOS, you also need the Xcode command line tools. On Windows, you need the Microsoft C++ Build Tools and WebView2.

```
npm install
npm run app
```
